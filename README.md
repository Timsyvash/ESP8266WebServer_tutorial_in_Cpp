# 🌐 ESP8266 Web Server (C++ / PlatformIO)

Простий та стабільний вебсервер на базі мікроконтролера **Wemos D1 mini (ESP8266)**, який дозволяє віддалено керувати цифровими виходами (GPIO) через вебінтерфейс у локальній мережі Wi-Fi.

---

## 📌 Особливості проєкту

* **Динамічний вебінтерфейс:** вбудована HTML/CSS сторінка з адаптивними кнопками для перемикання станів виходів (`ON` / `OFF`).
* **Захист від WDT (Watchdog Timer) та Bootloop:**
  * Оптимізована обробка HTTP-запитів із підтримкою `yield()` для віддачі часу фоновим процесам Wi-Fi.
  * Додано таймаут з'єднання для запобігання зависанню клієнтських сесій.
* **Безпечна розпіновка:** використання стабільних пінів `D1` (GPIO5) та `D2` (GPIO4), що усуває конфлікти при завантаженні прошивки.

---

## 🛠️ Компоненти та розпіновка (Pinout)

### Необхідні деталі:
1. **Wemos D1 mini** (ESP8266) — 1 шт.
2. **Світлодіоди або Модуль реле** — 2 шт.
3. **Обмежувальні резистори (220 Ом)** — 2 шт.
4. Якісний USB-кабель (з підтримкою Data-передачі та високого струму).

### Схема підключення:

| Компонент | Пін Wemos D1 mini | GPIO (ESP8266) | Примітка |
| :--- | :--- | :--- | :--- |
| **Output 1 (Реле / LED)** | **D1** | GPIO5 | Безпечний пін для керування |
| **Output 2 (Реле / LED)** | **D2** | GPIO4 | Безпечний пін для керування |
| **GND** | **GND** | GND | Спільний мінус |
